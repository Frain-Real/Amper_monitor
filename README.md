# Монитор потребления тока

Проект цифрового монитора потребления тока 

Работате со специальным приложением на ПК

Плата производит общение через COM port
Команды:
Запрос данных тока в формате float:
GET_ADC_XX (где XX цифра от 1 до 10)

Включение нужного канала мониторинга:
ON_CHANNEL_XX (где XX цифра от 1 до 10)

Выключение нужного канала мониторинга:
OFF_CHANNEL_XX (где XX цифра от 1 до 10)

ID устройства: amper_monitor
